Gateway · SDK 0.4.0

Theo dõi tín hiệu cuộc gọi realtime

Hướng dẫn ngắn để cài SDK, mở một kết nối theo agent_slug và ghi nhận mọi thay đổi trạng thái theo call_id. Ví dụ chỉ dùng biến môi trường, không chứa thông tin xác thực thật.

1. Cài đặt và cấu hình

Node.js

npm install asterisk-ai-agent-gateway-sdk@0.4.0

Python

python -m pip install asterisk-ai-agent-gateway-sdk==0.4.0
export GATEWAY_URL="https://gateway.example.com"
export GATEWAY_API_KEY="agw_live_your_key"
export GATEWAY_AGENT_SLUG="support-agent"

Dùng Node.js 18.17+ hoặc Python 3.10+. Thay URL, API key và slug bằng thông tin được cấp. SDK tự xác thực, giữ phiên và kết nối lại khi cần. Mỗi agent_slug chỉ nên có một kết nối đang chạy; kết nối mới nhất sẽ tiếp quản.

2. Quy ước tín hiệu

outbound.accepted chỉ xác nhận Gateway đã nhận yêu cầu; chưa có nghĩa là đầu kia đã trả lời. call.started mới xác nhận cuộc gọi đã trả lời và media đã sẵn sàng. Khi kết thúc, giải phóng state theo call.ended.

statusÝ nghĩaKết thúc?
dialingGateway đã nhận yêu cầu, chưa có trả lời.Không
ringingĐầu nhận đang đổ chuông.Không
answeredĐã trả lời; chờ call.started trước khi xử lý media.Không
completedCuộc gọi đã trả lời rồi kết thúc.Có
busyĐích đang bận.Có
no_answerKhông trả lời hoặc hết thời gian chờ.Có
rejectedYêu cầu bị từ chối.Có
unavailableĐích không khả dụng hoặc không có route.Có
failedLỗi khi thiết lập hoặc xử lý cuộc gọi.Có
cancelledBị hủy trước khi trả lời.Có
Bảy trạng thái terminal là completed, busy, no_answer, rejected, unavailable, failed và cancelled. sequence chỉ tăng trong chuỗi call.status; nếu cần loại trùng, dùng cặp (call_id, sequence). call.started.sequence độc lập và không được so sánh với sequence của status.

3. Node.js: ghi JSON theo call_id

Lưu ví dụ vào track-signals.mjs, chạy node track-signals.mjs. Hàm recordSignal in JSON ra stdout; thay thân hàm bằng phần ghi dữ liệu của ứng dụng nếu cần lưu lâu dài.

import { GatewayClient } from "asterisk-ai-agent-gateway-sdk";

const KNOWN = new Set([
  "dialing", "ringing", "answered", "completed", "busy",
  "no_answer", "rejected", "unavailable", "failed", "cancelled",
]);
const TERMINAL = new Set([
  "completed", "busy", "no_answer", "rejected", "unavailable", "failed", "cancelled",
]);

function recordSignal(record) {
  console.log(JSON.stringify({ observed_at: new Date().toISOString(), ...record }));
}
function statusRecord(event, type = "call.status") {
  const { call_id: callId, status } = event;
  return { type, call_id: callId, status,
    terminal: event.terminal === true || TERMINAL.has(status), answered: event.answered === true,
    reason: event.reason, hangup_cause: event.hangup_cause, dial_status: event.dial_status,
    sequence: event.sequence, updated_at: event.updated_at };
}

const client = new GatewayClient({
  gatewayUrl: process.env.GATEWAY_URL,
  apiKey: process.env.GATEWAY_API_KEY,
  agentSlug: process.env.GATEWAY_AGENT_SLUG ?? process.env.AGENT_SLUG ?? "support-agent",
});

client.on("call.status", (event) => {
  if (!KNOWN.has(event.status)) return;
  recordSignal(statusRecord(event));
});
client.on("call.started", (event) => recordSignal({
  type: "call.started", call_id: event.call_id, answered: true,
}));
client.on("call.ended", (event) => recordSignal(statusRecord(event, "call.ended")));
client.on("error", (error) => console.error(JSON.stringify({
  type: "sdk.error", name: error?.name, message: error?.message,
})));

await client.start();

4. Python: callback async cho cùng contract

Lưu ví dụ vào track_signals.py, chạy python track_signals.py. Callback nhận từng event JSON. Nếu cần giữ state tạm, chỉ giữ các cuộc gọi đang hoạt động và xóa ở call.ended.

import asyncio
import json
import os
from datetime import datetime, timezone

from asterisk_ai_gateway import GatewayClient

KNOWN = {"dialing", "ringing", "answered", "completed", "busy", "no_answer",
         "rejected", "unavailable", "failed", "cancelled"}
TERMINAL = {"completed", "busy", "no_answer", "rejected", "unavailable", "failed", "cancelled"}

def record_signal(record: dict) -> None:
    print(json.dumps({"observed_at": datetime.now(timezone.utc).isoformat(), **record},
                     ensure_ascii=False), flush=True)

def status_record(event: dict, kind: str = "call.status") -> dict:
    status = event.get("status")
    return {"type": kind, "call_id": event.get("call_id"), "status": status,
            "terminal": event.get("terminal") is True or status in TERMINAL,
            "answered": event.get("answered") is True,
            "reason": event.get("reason"), "hangup_cause": event.get("hangup_cause"),
            "dial_status": event.get("dial_status"), "sequence": event.get("sequence"),
            "updated_at": event.get("updated_at")}

async def on_event(event: dict) -> None:
    kind = event.get("type")
    call_id = event.get("call_id")
    if kind == "call.status":
        status = event.get("status")
        if status not in KNOWN:
            return
        record_signal(status_record(event))
    elif kind == "call.started":
        record_signal({"type": kind, "call_id": call_id, "answered": True})
    elif kind == "call.ended":
        record_signal(status_record(event, "call.ended"))
    elif kind == "error":
        record_signal({"type": "sdk.error", "code": event.get("code"),
                       "message": event.get("message")})

async def main() -> None:
    client = GatewayClient(
        gateway_url=os.environ["GATEWAY_URL"],
        api_key=os.environ["GATEWAY_API_KEY"],
        agent_slug=os.environ.get("GATEWAY_AGENT_SLUG") or os.environ.get("AGENT_SLUG", "support-agent"),
    )
    await client.run(on_event=on_event)

if __name__ == "__main__":
    asyncio.run(main())
